TROUBLESHOOTING

Back to your words.

Start with the message speechTexto shows after dictation.

Recording works, but no words appear

  1. In speechTexto → Settings, select Type at cursor.
  2. Open App access and confirm that access is on. System Settings may call Accessibility “Device Control and Data Access.”
  3. Choose Test typing. speechTexto opens a temporary TextEdit document and types a fixed sample without recording audio.
  4. Click in your destination editor before holding Right Option. Keep the same app, cursor and selection active until insertion finishes.

“Inserted” means the app observed the expected text change. “Check your editor” means keyboard input was sent but the change could not be confirmed. Check before retrying to avoid duplicate text.

If an editor doesn’t accept keyboard typing, select Paste compatibility mode in Settings or use Copy. App compatibility is not universal.

The microphone is unavailable

Open System Settings → Privacy & Security → Microphone and allow speechTexto. If permission is restricted by an administrator, contact them. Check your Mac’s selected input device, then try another short recording. speechTexto does not need Apple’s Speech Recognition permission.

Right Option doesn’t start recording

Use the Option key on the right side of Space and hold it until the listening panel appears. Quick taps and Option combinations are ignored. Enable Accessibility access and close older copies of speechTexto or Murmur. If your keyboard has no Right Option, choose Option–Space in Settings.

Keep a copy handy

The floating result panel stays visible for 15 seconds. Hover over it to keep it open. Copy is also available beside your latest transcript in the main window. Option–Shift–V inserts that transcript into another focused editor using your selected delivery method.

Words sound wrong

Select the language you are actually speaking. Add names or product terms to Personal vocabulary in Settings. Use a quiet environment and check the microphone input. The model supports seven languages; Hindi and Marathi are unsupported. Recordings stop at 30 seconds.

Permission appears on after a preview upgrade, but access is blocked

Local development builds can receive a new code signature when replaced. Check permission status inside speechTexto as well as System Settings. Contact support before resetting permissions. Public releases are planned to use a stable Apple Developer ID identity.

Why isn’t this on the Mac App Store?

speechTexto’s current cursor-typing design uses Accessibility APIs that Apple documents as incompatible with App Sandbox. The planned public edition is a direct download signed with Developer ID and notarized by Apple. Signing and notarization are pending; the current local build is a preview.
